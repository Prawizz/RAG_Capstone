# ชุดคำถามวัดผล retrieval — `eval/datasets/questions.jsonl`

คำถามที่**คนเขียนเอง** ใช้วัดว่าระบบค้นเจอหน้าที่มีคำตอบไหม และปฏิเสธถูกไหมเมื่อเอกสารไม่มีคำตอบ

ทำไมไม่ใช้ `rag_evaluation_100/1000.jsonl`: คำตอบของ KBANK 88/167 ข้อมาจากข้อความที่ดึงพัง (ขัด CLAUDE.md ข้อ 6), 1000 ข้อมาจากแม่แบบ 6 แบบ (exact_match 400 ข้อมีคำตอบไม่ซ้ำแค่ 70) และไม่มีเลขหน้าอ้างอิง

## กติกาทีม

- ทำบน `main` · แตะแค่ `eval/datasets/questions.jsonl` · `git pull` ก่อนเริ่มทุกครั้ง
- อ่าน `CLAUDE.md` ข้อ 6 — ห้ามสร้างคำตอบที่ถูกจากผลของโปรแกรมเรา (extractor / normalizer / ระบบค้น)

## รูปแบบ (1 บรรทัด = 1 ข้อ)

```json
{"id": "q001",
 "query": "ซีพี ออลล์ ปี 68 มีสาขาเซเว่นกี่สาขา",
 "register": "staff",
 "type": "number",
 "answer": "15,245 สาขา",
 "evidence": [{"file": "E_ONE_REPORT_CPALLT.PDF", "page": 12}],
 "evidence_text": "ข้อความในเอกสารที่ใช้ตอบ พิมพ์ตามที่ตาเห็น",
 "note": ""}
```
(ตัวเลขในตัวอย่างเป็นค่าสมมติ)

| ช่อง | ค่า |
|---|---|
| `register` | `staff` = คำค้นสั้นแบบพนักงาน · `customer` = ข้อความแบบลูกค้า ยาวกว่า สุภาพ มีบริบทก่อนถาม พิมพ์ผิดได้ |
| `type` | `fact` / `number` / `list` / `multi_hop` (ต้องใช้หลักฐาน 2 ที่ขึ้นไป) / `unanswerable` |
| `evidence` | PDF: `{"file", "page"}` (page = ลำดับหน้าใน PDF viewer เริ่มที่ 1) · DOCX: `{"file", "heading": "1.2.1 ส่วนบทนำ"}` · PPTX: `{"file", "slide": 20}` · XLSX: `{"file", "sheet", "cell": "D12"}` |
| `unanswerable` | `answer: null`, `evidence: []` |

## สัดส่วน (~80 ข้อ)

| แหล่ง | จำนวน |
|---|---|
| CPALL | 20 |
| PTT | 20 |
| KBANK | 10 — ใส่ `"note": "ต้อง OCR"` (ทั้งไฟล์รอ OCR) |
| ไฟล์ Office ใน `eval/datasets/files/` | 10 |
| ไม่มีคำตอบในเอกสาร | 20 — ครึ่งหนึ่งเป็น**เรื่องใกล้เคียง** เช่น ถามของ PTT ที่มีแต่ใน KBANK หรือถามปีที่ไม่มีในรายงาน |

`staff` / `customer` อย่างละครึ่ง · `multi_hop` อย่างน้อย 8 ข้อ

## หลักการเขียน

1. **อ่านหน้าก่อน แล้วถามแบบที่คนจริงจะถาม** อย่าลอกประโยคในเอกสารมาเปลี่ยนเป็นคำถาม (เอกสารเขียน "จำนวนสาขาทั้งสิ้น" → ถาม "มีกี่ร้าน") ไม่งั้นการค้นด้วยคำตรงตัวจะได้คะแนนดีเกินจริง
2. **`evidence_text` พิมพ์จากที่ตาเห็น** — CPALL / PTT ก๊อปมาได้แต่ต้องเทียบกับภาพก่อน · KBANK ห้ามก๊อป (ข้อความในไฟล์พัง)
3. **กระจายหน้า** — ย่อหน้า ตาราง ตัวเลข หน้าท้ายเล่ม ไม่ใช่แค่หน้าแรกๆ
4. ไม่แน่ใจคำตอบ → เขียนไว้ใน `note` อย่าเดา
