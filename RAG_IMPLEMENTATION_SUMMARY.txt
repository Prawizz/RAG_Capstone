1. ภาพรวมสถาปัตยกรรม (Architecture Overview)
--------------------------------------------------------------------------------
พัฒนาระบบสืบค้นและอ้างอิงข้อมูลระดับองค์กรสำหรับภาษาไทยและเอกสารหลากภาษา
ตามแนวทาง SOTA (State-of-the-Art) โดยเป็นอิสระจากโดเมน (Domain-Agnostic) 
ไม่ผูกติดหรือฮาร์ดโค้ดชื่อบริษัทหรือคีย์เวิร์ดเฉพาะทางใดๆ

Pipeline การทำงานหลัก:
  File Ingestion (PDF/Office) 
    -> Thai Normalization (ล้าง Noisy Whitespace)
    -> Thai-Aware SBD Hierarchical Chunking (Child + Parent)
    -> Contextual Retrieval Indexing (Anthropic Framework 2024)
    -> Hybrid Search: Contextual BM25+ (Lv & Zhai, 2011) + Dense BGE-M3 (1024-dim)
    -> Reciprocal Rank Fusion (RRF k=60)
    -> ColBERT MaxSim Token-to-Token Mutual Interaction Reranker
    -> Multi-Tiered Abstention Gate (Conformal Prediction ป้องกัน Hallucination)
    -> Sentence-level Citation Packaging (ALCE / LongCite [S1], [S2])


2. รายละเอียดของโมดูลที่พัฒนา (Core Modules)
--------------------------------------------------------------------------------
[1] app/chunking.py (Thai-Aware Hierarchical Chunker)
    - Dual-path Thai Sentence Boundary Disambiguation (SBD):
      ใช้ PyThaiNLP crfcut ร่วมกับ Rule-based newline/punctuation
    - Hierarchical 2-Layer Chunking:
      * Child Chunk: ระดับประโยคเดี่ยว เก็บ char_start / char_end offsets ดั้งเดิมเป๊ะ
      * Parent Chunk: หน้าต่าง 3-5 ประโยค (Sliding window overlap 1 ประโยค)
    - Anthropic Contextual Retrieval (2024):
      เพิ่ม property `contextual_text` ผนวกชื่อเอกสารและหัวข้อ (heading_path)
      เข้ากับ Chunk สำหรับ Indexing โดยไม่ทำลาย snippet ดั้งเดิม
    - ตัดข้อความปลอดภัยด้วย Grapheme Cluster (`\X`) สระ/วรรณยุกต์ไม่ลอย

[2] app/embedding.py (Dense Semantic Embedding Model)
    - สเปก BAAI/bge-m3 เวกเตอร์หนาแน่น 1024 มิติ
    - ฟังก์ชันคำนวณ Cosine Similarity: sim(q, d) = (q · d) / (||q|| * ||d||)
    - รองรับ Fallback L2-Normalized Semantic Subword Hashing ในตัว
      ทำให้รัน CI และ Unit Test ได้ทันทีโดยไม่ต้องดาวน์โหลดโมเดลขนาดใหญ่

[3] app/retrieval.py (Hybrid Search, RRF & Abstention Gate)
    - Thai BM25+ Engine: อ้างอิง Lv & Zhai (2011) พร้อม delta = 1.0 
      และ Tokenization 2 ระดับ (newmm + TCC ควบคู่ Subword/Alphanumeric N-grams)
      คำนวณ IDF จากคลังข้อมูลจริง ไม่มีฮาร์ดโค้ด
    - Dense Vector Search: ค้นหาความหมายเชิงอรรถศาสตร์ร่วมกับ BGE-M3
    - Reciprocal Rank Fusion (RRF k=60) & Relative Score Fusion (RSF alpha=0.65)
    - ColBERT MaxSim Reranker: คำนวณ Token-to-Token Mutual Alignment ระหว่างคำถามและเอกสาร
    - Multi-Tiered Abstention Gate:
      * Tier 1 (Retrieval Gate): ตรวจสอบ Conformal Query Coverage (< 0.40 -> Fast-Abstain)
      * Tier 2 (Uncertainty Gate): Semantic Entropy Check
      * Tier 3 (Entailment Gate): Grounding Ratio Check
      * Fallback message มาตรฐาน: "ขออภัย ระบบไม่พบข้อมูลที่เพียงพอในเอกสารองค์กรสำหรับการตอบคำถามนี้ได้อย่างถูกต้อง"

[4] app/citations.py (Sentence-level Citation Builder & ALCE Framework)
    - แปลง Child Chunks เป็น Citation Objects ที่มี ID [S1], [S2] ชี้กลับตำแหน่งจริง
    - ตรวจสอบ Citation Recall และ NLI Entailment Score หลังการสร้างคำตอบ

[5] app/ingest.py (Full Ingestion Coordinator)
    - IngestionService คลาสประสานงานหลัก: Extract -> Chunk -> Embed -> Index -> Query
    - รองรับการนำเข้าแบบทั้งไฟล์ หรือเจาะจงช่วงหน้า (tuple / list of pages)


3. สคริปต์สำหรับทดสอบและใช้งาน (Executable Scripts)
--------------------------------------------------------------------------------
- scripts/run_full_pipeline.py:
  สคริปต์หลักสำหรับรัน End-to-End Pipeline ครบวงจร
